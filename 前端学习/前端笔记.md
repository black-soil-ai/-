#### 1.1标签选择器

> 直接通过html标签来设置样式

#### 1.2类选择器

> .类名{}

```tex
1. class属性称为类
2. 类可以由数字、字母、下划线组成，但是不能以下划线/数字开头
3. 一个标签可以有多个类名
```

#### 1.3 id选择器

> #id名{}

```tex
1. id属性值类似于身份证号码，是唯一的
2. 一个标签只能有一个id
```

#### 1.4通配符选择器

> 对页面的所有标签进行设置

```css

    padding:0;
}
```

#### 1.5后代选择器

> A  B{
>
> ​	属性名：属性值；
>
> }
>
> A是父代，B是子代
>
> 这里的A、B可以是类也可以是id

#### 1.6子代选择器

> A>B{
>
> ​	属性名：属性值；
>
> }

#### 1.7伪类选择器

> 用于处于特定状态的元素

```css
/*:hover:鼠标悬停的元素*/
a:hover{}
/*:active:处于激活状态的元素*/
button:active{}
/*:focus:选中焦点的元素，如输入框*/
input:focus{}
/*:first-child:选中某个父元素下的第一个子元素*/
ul>li:first-child{}
/*:last-child选中某个父元素下的最后一个子元素*/
ul>li:last-child{}
/*:nth-child():选中父元素下指定的某个元素*/
ul>li:nth-child(3){}
```

#### 1.8选择器权重

> 权重越大，优先级越高

| 选择器类型       | 示例                             | 权重值（方便对比） |
| ---------------- | -------------------------------- | ------------------ |
| !important       | `color: red !important;`         | 无穷大（最高）     |
| 内联样式         | `<div style="color: red"></div>` | 1000               |
| ID 选择器        | `#header`                        | 100                |
| 类 / 伪类 / 属性 | `.box` / `:hover` / `[type]`     | 10                 |
| 元素 / 伪元素    | `div` / `p` / `::before`         | 1                  |
| 通配符 / 继承    | `*` / 继承来的样式               | 0                  |

## 3.盒子模型

> 页面中的每个标签都可以看作是个盒子，即浏览器中的一个个矩形区域

- 内容 content
- 内边距 padding
- 边框 border
- 外边距 margin

#### 3.1盒子的属性

> 1.内容设置
>
> `width: 100px
> height: 100px`

> 2.边框设置`border`
>
> `.box{
> 	border: 2px solid black;
> }`

```tex
1. solid：实线边框，用一条实线来显示边框
2. dashed：虚线边框，用短划线来显示边框
3. dotted：点线边框，用小圆点来显示边框
4. double：双线边框，显示两条实线边框
5. groove：3D 凹槽边框，效果看起来像是镂空
的
6. ridge：3D 凸槽边框，效果看起来像是突出的
7. inset：3D 内阴影边框，效果类似于元素被镶嵌
在页面中
8. outset：3D 外阴影边框，效果类似于元素凸出
于页面上
9. hidden：隐藏边框，不显示边框，但在布局中
仍然占据空间
10. none：无边框，完全不显示边框，也不占据空间
--------------------------------------
border-top: 10px solid red; /* 设置盒子的上边框 */
border-right: 10px solid green; /* 设置盒子的右边框 */
border-bottom: 10px solid yellow; /* 设置盒子的下边框 */
border-left: 10px solid black; /* 设置盒子的左边框 */

```

[^注意]:设置边框会撑大盒子

> 3.内边距

> `padding: 上 右 下 左`

```tex
padding: 10px 20px 30px 40px; /*上:10px 右:20px 下:30px左:40px */
```

> 4.外边距
>
> `margin: 上 右 下 左;`
>
> 具体用法与上方相同

#### 3.2盒子的计算方式`box-sizing`

> `box-sizing`可以改变盒子大小的计算方式

```tex
1. box-sizing: content-box; 默认值
盒子最终呈现的大小 =(width、height属性设置的大小) + 边框大小 + 内边距大小
2. box-sizing: border-box;
盒子最终呈现的大小 = width、height属性设置
的大小
```

#### 3.3盒子的显示方式`display`

> display 属性控制元素如何显示在页面上
>
> `display: block`
>
> `display: inline`
>
> `display: inline-block`
>
> `display: none`

```tex
1. block
将元素显示为块级元素，可以设置宽度、高度、内外边距等属性
2. inline 
将元素显示为行内元素，宽度和高度由内容决定，无法设置宽度和高度
3. inline-block
将元素显示为行内块级元素。行内块可以在一行内展示，并且可以设置宽度、高度、内外边距等属性
5. none
将元素彻底隐藏。后续元素会占据这个元素的位置
```

## 4.定位

| 定位方式         | 属性值     | 核心特点                      | 参照物                                     | 典型用途                                         |
| ---------------- | ---------- | ----------------------------- | ------------------------------------------ | ------------------------------------------------ |
| 静态定位（默认） | `static`   | 正常文档流，不受偏移值影响    | 无（浏览器默认布局）                       | 元素默认状态                                     |
| 相对定位         | `relative` | 保留原位置                    | **自身原来的位置**                         | 微调元素位置；或作为 `absolute` 元素的父级参照物 |
| 绝对定位         | `absolute` | 脱离文档流，                  | **最近的非 `static` 祖先元素**（无则视口） | 做悬浮层、弹窗、子元素精准定位                   |
| 固定定位         | `fixed`    | 脱离文档流,根据浏览器进行移动 | **浏览器视口（窗口）**                     | 固定导航栏、悬浮按钮、回到顶部按钮               |

| 方向 |  属性名  |
| :--: | :------: |
| 水平 |  `left`  |
| 水平 |  `righ`  |
| 垂直 |  `top`   |
| 垂直 | `bottom` |

#### 4.1固定定位`fixed`

> `position: fixed`
>
> 在页面中不占位置，位置参考只有窗口

#### 4.2相对定位`relative`

> `position: relative`
>
> 1.根据原本的位置进行移动
>
> 2.配合绝对定位组一对

#### 4.3绝对定位`relative`

> 与相对定位`relative` 相配合
>
> 子元素用 `position: absolute;`（绝对位），父元素用 `position: relative;`（相对定位）
>
> 目的：让子元素的定位以父元素为参照物

#### 4.4显示层级`z-index`

> `z-index: 整数；`
>
> 设置盒子的显示层级 范围（-♾~+♾）
>
> 正整数（如 1 , 100 ）：表示较高的层级。 
>
> 负整数（如 -1 , -100 ）：表示较低的层级。 auto （默认值）：表示不指定 z-index ，元素 按照默认堆叠顺序排列。

## 5.常用样式属性

#### 5.1文本基线`vertical-align`

> `vertical-align`控制行内元素或行内块元素垂直对齐的重要属性
>
> 默认值是baseline 基线对齐

```tex
1. 基线对齐 ( baseline ): 默认值。元素的基线与父元素的基线对齐。
2. 顶部对齐 ( top ): 元素的顶部与行内元素或单元格的顶部对齐。
3. 底部对齐 ( bottom ): 元素的底部与行内元素或单元格的底部对齐。
4. 中线对齐 (middle) : 元素的中线与行内元素或单元格的中线对齐。
5. 文本顶部对齐 ( text-top ): 元素的顶部与文本字体的顶部对齐。
6. 文本底部对齐 ( text-bottom ): 元素的底部与文本字体的底部对齐。
7. 子元素基线对齐 ( sub ): 元素的基线放置在父元素基线的下方，用于下标文本。
8. 上标基线对齐 ( super ): 元素的基线放置在父元素基线的上方，用于上标文本。
```

#### 5.2滚动条`over-flow`

```tex
overflow: visible;默认值，内容溢出时不会显示滚动条，内容会超出容器边界。
overflow: hidden;隐藏溢出的内容，不显示滚动条。
overflow: scroll;始终显示滚动条，无论内容是否溢出。
overflow: auto;当内容溢出时自动显示滚动条，否则隐藏滚动条。
---------------------------------------
可以使用 overflow-x 和 overflow-y 分别控制水平和垂直滚动条
```

#### 5.4盒子背景`background-image`

> `background-image: url('图片路径')`

1. 控制图片是否重复`background-repeat`

```tex
repeat(默认值) 图片在水平和垂直方向上重复
no-repeat 图片不重复
repeat-x  在x轴上重复
repeat-y  在y轴上重复
```

2. 控制背景图片的尺寸`bachground-size`

```tex
auto(默认值)  保持图片原始大小
设置具体尺寸  （200px,100px）
设置百分比     (50%,50%)
cover     缩放图片，完全覆盖容器(会裁剪部分)
contain    缩放图片，最大的完整显示，可能会留白
```

3. 控制图片的初始位置`background-position`

```tex
水平方向：left,right,center
竖直方向：top,botton,center
也可以填具体的数值或者百分比
```

4. 多张背景图

```tex
div {
	background-image:url('image1.jpg'), url('image2.jpg');
	background-repeat: no-repeat, repeat;
	background-position: top left, bottom right;
	background-size: 200px 100px, auto;
}

第一张图片（ image1.jpg ）位于左上角，不重复，尺寸为 200 x 100 。
第二张图片（ image2.jpg ）位于右下角，重复显示，保持原始尺寸。
```

#### 5.5盒子阴影`box-shadow`

- 创建卡片式布局的阴影效果
- 增强悬浮按钮或交互效果

> `box-shadow:5px 5px 10px 10px #000`

```tex
box-shadow: offset-x offset-y blur-radius spread-radiuscolor inset;

offset-x ：水平偏移量（正值向右，负值向左）。
offset-y ：垂直偏移量（正值向下，负值向上）。
blur-radius ：模糊程度（可选，默认为 0）值越大，阴影越模糊。
spread-radius ：扩展半径（可选，默认为 0）。正值扩大阴影，负值缩小阴影。
color ：阴影颜色（可选，默认为黑色）。
inset ：内阴影关键字（可选）。如果指定，则阴影出现在元素内部。
```

#### 5.6 `cursor`

> 设置鼠标的显示形式
>
> `cursor: url('./image/大白菜.png'), pointer;`

```tex
pointer :手型指针，通常用于表示可点击的链接或按钮。
text ：文本输入指针（I形），通常用于表示可编辑的文本区域。
wait ：等待指针（沙漏或旋转圈），通常用于表示加载或处理中。
help ：帮助指针（带问号的箭头），通常用于表示需要帮助或更多信息。
move ：移动指针（四向箭头），通常用于表示元素可以被拖动。
e-resize ：水平调整大小指针（指向右的箭头），通常用于表示元素可以水平调整大小。
n-resize ：垂直调整大小指针（指向上或下的箭头），通常用于表示元素可以垂直调整大小。
ne-resize ：右上角调整大小指针（斜向箭头），通常用于表示元素可以沿右上角调整大小。
nw-resize ：左上角调整大小指针（斜向箭头），通常用于表示元素可以沿左上角调整大小。
not-allowed ：禁止指针（圆圈加斜杠），通常用于表示操作被禁止。
```

## 6.`Flex`布局

> 什么是Flex?
>
> 灵活的响应式布局，可以轻松的对齐和分配空间，尤其是动态内容和未知大小的元素。

- 创建水平或者竖直排列的布局
- 实现居中对齐（水平/竖直）
- 动态调整子元素的大小
- 构建导航栏、卡片布局、网格系统

### 6.1定义主轴方向

> `.container{
> 	display:flex;
> 	flex-direction:column;
> }`

```tex
1. row 默认，子元素沿着水平方向从左到右排列
2. row-reverse 子元素沿着水平方向从右到左排列
3. column 子元素竖直排列
4. column-reverse 子元素沿着竖直方向从下到上排列
```

### 6.2主轴对齐方式

> `.container{
> 	display:flex;
> 	justify-content:center;
> }`

```tex
1. flex-start 子元素全部靠左
2. flex-end 子元素全部靠右
3. center 子元素整体居中
4. space-between 子元素均匀分布，首尾贴近开头和结尾
5. space-around 每个元素周围的间距相等
6. space-evently 每个子元素间距以及子元素和容器边缘间距相等
```

### 6.3副轴对齐方式

> `.container{
> 	diaplay:flex;
> 	align-items:center;
> 	height: 200px;
> }`

```tex
当副轴是竖直方向的情况下
1. stretch 默认，子元素会被拉伸填满整个父容器的竖直方向，如果子元素设置了高度的话就失效了
2. flex-start 全部挤在最上方
3. flex-end 全部挤在最下方
4. center 居中对齐
5. baseline 文字底部的线对齐
```

### 6.4子元素允许换行与行列间距

> 当子元素宽度大于容器时会自动换行(默认不换行)
>
> `.container{
> 	display:flex;
> 	flex-wrap;
> }`

```tex
1. nowrap 默认，不允许换行
2. wrap 允许换行
3. wrap-reverse 向上换行
--------------------------------------
gap: 20px   行列间距都为20px
gap: 10px 20px  行间距为10px,列间距为20px
```
